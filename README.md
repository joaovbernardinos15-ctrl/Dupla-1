# Domino's Pizza Website

Projeto de uma landing page para pizzaria inspirado na Domino's Pizza, desenvolvido com HTML, CSS e JavaScript.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- AOS Animation Library
- Font Awesome
- Google Fonts

## Funcionalidades

- Página responsiva
- Animações ao rolar a página
- Seção sobre a empresa
- Cards de pizzas com preços
- Integração com WhatsApp
- Integração com Google Maps
- Ícones de redes sociais
